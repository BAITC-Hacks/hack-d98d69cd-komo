# Импорт Excel/JSON и скачиваемые шаблоны — 23.09.2026

Реализованы кнопка «Скачать шаблон», выбор Excel/JSON, единый файл профилей и истории, отдельные файлы истории Excel/JSON/CSV. Скачивание разрешено только HR. Форматы приводятся к общей атомарной проверке предметных данных.

## Проверки

- 8 новых backend-тестов проходят на текущих исходниках: эквивалентность шаблонов, перестановка колонок, пустые строки, даты Excel, невалидные уровни, формулы, поврежденный файл, JSON-массивы, CSV с `;`, права, повторный импорт и отсутствие частичной записи при ошибке ссылки.
- До внешнего сброса Git общий набор второго прохода и импорта: 48 passed. Это результат той сборки, не утверждение о восстановлении второго прохода в текущей рабочей копии.
- Браузерный сценарий на localhost:3000: скачивание Excel → замена ID на новые QA_R2 → импорт профиля и истории → повтор без дубликатов → скачивание и импорт JSON → ошибка поврежденного Excel. 1 passed за 3.6 с, ошибок JavaScript нет.
- Проверен экран 390 px без горизонтального переполнения. Визуально просмотрены страница шаблонов, успешный импорт и ошибка на мобильном экране. Скриншоты — `artifacts/import-formats`.
- TypeScript проходит. Frontend с кнопкой и API с новыми зависимостями успешно собраны в Docker; запущенное приложение содержит эту сборку.
- Excel-шаблон экспортирован, прочитан серверным парсером и сопоставлен с JSON. Визуально проверены все семь листов. Шаблоны не содержат реальных персональных данных.

В тестах добавлены только новые синтетические QA_R2-профили. Существующие записи не удалялись. Коммиты и push агентом не выполнялись.

# Собственные проверочные профили

Это дополнительные синтетические примеры команды, **не скрытые профили жюри**. Исходный датасет не изменяется.

В HR → Импорт загрузите `employees.json` и `activity_history.csv` из этой папки совместно.

- `CQ_CASE_01`: минимальный Public Speaking и три пропуска клуба; критический разрыв в System Design. Первым полезнее шаг для системного проектирования.
- `CQ_CASE_02`: prerequisite для High-Load Systems не выполнен; Cloud/CICD уже выше потолка курса. EV_006 и EV_009 должны быть исключены.
- `CQ_CASE_03`: переход Data Analyst → Product Manager, история отсутствует. Цель и допуски должны учитываться отдельно; прошлые успехи нельзя выдумывать.

Повторный импорт не добавляет дубликаты. Расчетное сегодня: 2026-10-01.

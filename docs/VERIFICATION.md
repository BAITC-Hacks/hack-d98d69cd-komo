## AI: проверенный отказ, успешный вызов пока не подтвержден

Реальный запрос отправлен в OpenAI Responses API с настроенной моделью `gpt-4.1-mini-2025-04-14`. Провайдер вернул **401 Unauthorized / AuthenticationError**. Повтор после пересоздания API с текущим `.env` дал тот же результат.

Приложение вернуло HTTP 200 с `source=fallback`, тремя допустимыми шагами и четырьмя группами фактов для каждого. Последний измеренный ответ — 0.597 с. Интерфейс явно обозначает резервный подбор.

Проверено отсутствие лишних пробелов/кавычек в загруженном ключе и отсутствие идентифицирующих полей сотрудника в исходящем payload. Ключи и отпечатки не публикуются.

Backend-тесты используют явную фикстуру провайдера; они доказывают валидацию и интеграцию, но не успешную работу модели. Для закрытия AI-проверки нужен принятый OpenAI ключ и успешный `python -m app.smoke_ai` с `source=ai`, непустыми шагами и `cached=false`.
